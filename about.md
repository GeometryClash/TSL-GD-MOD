# TSL Mod

A simple Geometry Dash mod that displays the position of a level on The Shitty List (TSL).

The TSL position is shown directly on the level info screen and in level lists, making it easy to see where a level ranks on TSL without having to check the list separately.

### Features

* Shows TSL positions on level info screens
* Shows TSL positions in level lists
* Automatically fetches the latest TSL data
* Optional `Enabled` setting
* Only displays a position when the level is on TSL
